# 银发通 — 老年医学知识库

## 概述

本知识库专为银发通 Dify AI 智能导诊工作流设计，覆盖老年患者常见疾病的症状识别、科室推荐、OTC 用药参考及老年特殊注意事项。

## 使用方法

### 上传至 Dify 知识库

1. 登录 cloud.dify.ai 或你的自托管 Dify 实例
2. 进入「知识库」→ 创建知识库 → 名称："银发通-老年医学知识库"
3. 上传方式选择「批量上传」，选中所有 `.md` 文件
4. 配置参数：
   - **分段方式**：自动分段与清洗
   - **分段最大长度**：500 tokens
   - **分段重叠长度**：50 tokens
   - **索引方式**：高质量（Embedding）
   - **Embedding 模型**：`text-embedding-3-small`（OpenAI 兼容）或 `bge-large-zh-v1.5`
5. 等待索引完成，测试检索质量

## 知识库维护

- **更新频率**：建议每季度复核一次，根据最新临床指南调整
- **扩充方向**：可增加药品说明书原文、护理操作指南、营养食谱等
- **去重原则**：同一种疾病/药品只保留一份权威文档

## 文档模板结构

每篇疾病文档包含以下章节（可根据需要增减）：

```markdown
# 疾病名称（English Name）
## 疾病概述
## 典型症状
## 方言/口语表述识别
## 推荐就诊科室
## 常用 OTC 药物参考
## 老年患者特别注意事项
## 紧急情况警示
```
