# 脑卒中（Stroke / Cerebrovascular Accident）

## 疾病概述
脑卒中（中风）是老年人致死致残的首要原因。分为缺血性（脑梗死，占 70-80%）和出血性（脑出血/蛛网膜下腔出血，占 20-30%）。高血压是首要危险因素。**时间就是大脑——每延迟 1 分钟，约有 190 万个神经元死亡。**

## 典型症状（FAST 原则识别）
- **F (Face)**：面部不对称，一侧口角歪斜、鼻唇沟变浅
- **A (Arms)**：一侧肢体无力或麻木，不能平举
- **S (Speech)**：言语含混不清、找词困难、不能理解他人说话
- **T (Time)**：出现以上任一症状，立即拨打 120，记录发病时间

其他表现：
- 突发剧烈头痛（"一生中最剧烈的头痛"——警惕蛛网膜下腔出血）
- 突发视力障碍（单眼或双眼视物模糊、视野缺损）
- 突发行走困难、失去平衡、晕眩
- 突发意识障碍、呼之不应

## 方言/口语表述识别

## 推荐就诊科室
**神经内科**（急性缺血性卒中）或 **神经外科**（出血性卒中、大血管闭塞取栓）/ **急诊科**（急性期直接去急诊）

## OTC 用药参考（二级预防/康复期，非急性期）

### 1. 阿司匹林肠溶片 (Aspirin)
- 适应症：非心源性缺血性卒中/TIA 的二级预防
- 用法用量：每日 75-100mg
- 老年注意：出血风险；高血压未控制者禁用
- 禁忌症：活动性出血、血小板减少

### 2. 甲钴胺 (Mecobalamin)
- 适应症：卒中后周围神经修复辅助
- 用法用量：每次 0.5mg，每日 3 次
- 老年注意：安全性好，可长期服用
- 禁忌症：过敏者

## 老年患者特别注意事项
1. **识别先兆**：一过性单侧肢体无力/麻木（TIA）是脑梗前兆，不要因为"自己好了"就不去医院——TIA 后 48 小时内卒中风险最高
2. **控制危险因素**：高血压（收缩压控制 <140）、房颤（需抗凝）、高血脂、糖尿病
3. **吞咽功能评估**：卒中后吞咽困难发生率 50%，喂食前需评估，防误吸
4. **预防跌倒**：偏瘫侧肢体笨拙+平衡障碍→跌倒高风险；康复期使用辅助器具
5. **情绪关注**：卒中后抑郁发生率 30-50%，家属注意观察患者是否情绪低落、拒食、失眠

## 紧急情况警示（时间窗口！）
- **黄金 4.5 小时**：急性缺血性卒中，发病 4.5 小时内到达医院可溶栓治疗
- **6 小时内**：大血管闭塞可行机械取栓
- **行动**：见到 FAST 任一症状→立即拨打 120，不要自己开车，不要等"看会不会好"，不要先吃降压药或阿司匹林
