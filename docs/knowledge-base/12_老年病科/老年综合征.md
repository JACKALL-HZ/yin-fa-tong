# 老年综合征与综合管理

## 一、老年综合征概述

老年综合征（Geriatric Syndrome）是指由多种因素共同作用导致的、超出单一器官系统范畴的老年健康问题。它不是一种"病"，而是一组症候群。核心特征：多因素→多后果→多学科干预。

## 二、核心老年综合征

### 1. 跌倒 (Falls)
- **流行病学**：65+ 社区老人每年跌倒率 30-40%，80+ 增至 50%
- **后果**：骨折（特别是髋部骨折）、颅内出血、害怕再次跌倒→活动减少→功能衰退→丧失独立生活能力
- **常见原因**：体位性低血压、药物（镇静安眠药/降压药/降糖药）、视力下降、下肢肌力减退、环境障碍
- **评估**：起身行走试验（TUG Test）>12 秒提示跌倒高风险

### 2. 多重用药 (Polypharmacy)
- **定义**：同时使用 ≥5 种药物（含 OTC 和保健品）
- **风险**：药物相互作用概率随用药数量指数上升；每种药都可能叠加副作用（便秘、嗜睡、跌倒）
- **管理**：每 3-6 个月由医师/药师进行药物重整（Medication Reconciliation）

### 3. 衰弱 (Frailty)
- **定义**：生理储备能力下降→应激状态下易发生不良结局
- **5 项表型标准**（Fried 标准，≥3 项为衰弱）：体重下降(>5%/年)、疲乏感、活动量减少、步速减慢(<0.8m/s)、握力下降
- **干预**：力量+抗阻运动（每周 2-3 次）、蛋白质补充（每日 1.2-1.5g/kg）、维生素 D 800-2000IU/日

### 4. 认知障碍与痴呆 (Cognitive Impairment & Dementia)
- 阿尔茨海默病（AD）占痴呆的 60-70%，65 岁后每 5 年患病率翻倍
- **10 个警示信号**：记忆力影响日常生活、计划/解决问题困难、做熟悉的事也困难、时空混淆、视觉/空间理解困难、言语表达/书写困难、物品放错地方且无法回溯、判断力下降、脱离社交、性格情绪改变
- **可逆性认知下降的排查**：甲状腺功能↓、维生素 B12 缺乏、药物副作用（抗胆碱能药）、抑郁症（"假性痴呆"）、正常压力脑积水

### 5. 尿失禁 (Urinary Incontinence)
- 老年女性患病率 30-60%，男性约 10-20%
- **类型**：压力性（咳嗽/打喷嚏时漏尿）、急迫性（尿意一来憋不住）、充盈性（糖尿病/前列腺增生→膀胱排空不全）、功能性（行动不便来不及去厕所）
- **非药物干预**：定时排尿（每 2-3 小时）、盆底肌锻炼（凯格尔运动）、减少咖啡因/酒精摄入

### 6. 营养不良 (Malnutrition)
- 社区老年患者营养不良或营养不良风险发生率 20-50%
- **原因**：牙齿咀嚼困难、味觉/嗅觉减退、食欲下降（药物/疾病）、独居（"随便吃两口"）、低收入、抑郁
- **筛查**：微型营养评估表（MNA-SF）；体重 3 个月内下降 >5% 警示

### 7. 睡眠障碍 (Sleep Disorders)
- 老年人睡眠结构变化：深睡眠减少、夜间觉醒增多、早醒→但总睡眠时间需求未显著减少
- 长期使用苯二氮䓬类安眠药→依赖、跌倒、认知损害（Beers 标准明确不推荐）
- **非药物干预**：固定起床时间、日间充分光照、下午 2 点后不喝咖啡茶、睡前温水泡脚、认知行为治疗

## 三、推荐就诊科室

**老年病科**（综合评估与管理，一站式解决多重问题）

## 四、老年综合评估（CGA）

老年病科的核心工具——不是看单一疾病，而是评估全维度：
1. 医学评估：完整用药清单、疾病控制情况
2. 功能评估：ADL（日常生活能力）/ IADL（工具性日常生活能力）
3. 认知心理评估：MMSE / MoCA / GDS（老年抑郁量表）
4. 社会环境评估：居住环境安全性、照护者状况、经济能力

- "睡觉不好、老醒"、"睡到两三点就醒了再也睡不着"
- "憋不住尿"、"一笑一咳就漏尿"
