# 老年患者常见药物相互作用

## 一、心血管药物相互作用

### 1. ACEI/ARB + NSAID
- **组合**：卡托普利/缬沙坦 + 布洛芬/双氯芬酸
- **后果**：降压效果减弱；肾功能恶化风险增加；高钾血症风险
- **建议**：尽量避免联用，必须联用时监测血压和肾功能

### 2. ACEI/ARB + 保钾利尿药
- **组合**：卡托普利/缬沙坦 + 螺内酯
- **后果**：严重高钾血症
- **建议**：尽量避免；心力衰竭患者医嘱联用时需严格监测血钾（目标 <5.0 mmol/L）

### 3. CCB + 葡萄柚汁
- **组合**：硝苯地平/非洛地平 + 葡萄柚汁
- **后果**：CYP3A4 被抑制，CCB 血药浓度升高 2-3 倍，导致严重低血压和心动过速
- **建议**：服药期间严格禁食葡萄柚及制品

### 4. 地高辛 + 大环内酯类抗生素
- **组合**：地高辛 + 克拉霉素/红霉素
- **后果**：地高辛血药浓度显著升高→洋地黄中毒（恶心、黄视、心律失常）
- **建议**：监测地高辛血药浓度（目标 0.5-0.9 ng/ml），必要时减量

## 二、抗凝/抗血小板药物相互作用

### 5. 华法林 + 抗生素/抗真菌药
- **组合**：华法林 + 甲硝唑/氟康唑/复方新诺明
- **后果**：CYP2C9 被抑制，INR 显著升高→严重出血
- **建议**：用药前测 INR；用药期间每 1-2 天监测 INR；抗生素疗程结束后重新调整华法林剂量

### 6. 华法林 + NSAID/阿司匹林
- **组合**：华法林 + 布洛芬/阿司匹林
- **后果**：胃肠道出血风险增加 3-6 倍；NSAID 可增强华法林抗凝效果
- **建议**：对乙酰氨基酚为较安全的止痛替代方案（监测 INR）

### 7. 阿司匹林 + 布洛芬
- **组合**：阿司匹林 + 布洛芬
- **后果**：布洛芬占据 COX-1 结合位点，阻断阿司匹林不可逆抗血小板作用
- **建议**：布洛芬应在阿司匹林服用后至少 2 小时后服用；或改用对乙酰氨基酚

### 8. 抗血小板药 + SSRI 类抗抑郁药
- **组合**：阿司匹林/氯吡格雷 + 舍曲林/氟西汀
- **后果**：SSRI 抑制血小板 5-HT 再摄取→血小板功能降低→出血风险增加
- **建议**：必要时联用，监测出血征象（皮肤瘀斑、黑便等）

## 三、降糖药物相互作用

### 9. 磺脲类 + 磺胺类抗生素
- **组合**：格列齐特/格列吡嗪 + 复方新诺明
- **后果**：严重持久的低血糖
- **建议**：首选替代抗生素；无法替代时减少磺脲类剂量并加强血糖监测

### 10. 二甲双胍 + 碘造影剂
- **组合**：二甲双胍 + 碘造影剂（增强 CT 等检查）
- **后果**：造影剂可导致一过性肾功能下降→二甲双胍蓄积→乳酸酸中毒（死亡率 50%）
- **建议**：检查前 48 小时至检查后 48 小时暂停二甲双胍；确认肾功能正常后再恢复使用

### 11. β 受体阻滞剂 + 降糖药
- **组合**：美托洛尔/普萘洛尔 + 胰岛素/磺脲类
- **后果**：β 阻滞剂掩盖低血糖的交感神经兴奋症状（心悸、震颤、出汗），但低血糖仍在发生
- **建议**：加强血糖监测；教育患者认识低血糖的非典型症状

## 四、神经系统药物相互作用

### 12. 苯二氮䓬类 + 其他中枢抑制剂
- **组合**：地西泮/阿普唑仑 + 酒精/阿片类/其他镇静药
- **后果**：协同中枢抑制→过度镇静→呼吸抑制→死亡
- **建议**：老年人原则上避免使用苯二氮䓬类；若必须使用，严格禁酒

### 13. SSRI + 曲马多
- **组合**：舍曲林/氟西汀 + 曲马多
- **后果**：5-羟色胺综合征（高热、意识障碍、肌阵挛、自主神经不稳定）
- **建议**：避免联用；需使用时至少间隔 14 天

### 14. 左旋多巴 + 高蛋白饮食
- **组合**：左旋多巴（帕金森病用药）+ 高蛋白食物
- **后果**：氨基酸竞争血脑屏障转运体→左旋多巴入脑减少→药效明显下降
- **建议**：左旋多巴餐前 30-60 分钟或餐后 2 小时服用；晚餐可适当增加蛋白摄入

## 五、中药-西药相互作用

### 15. 含丹参/三七 → 抗凝药
- **组合**：复方丹参滴丸/三七粉 + 华法林/阿司匹林/氯吡格雷
- **后果**：丹参/三七有抗血小板作用→与西药协同→出血风险显著增加
- **建议**：严格评估必要性；必须联用时监测 INR 和出血体征

### 16. 含甘草 → 降压药/利尿药
- **组合**：复方甘草片/甘草剂 + 氢氯噻嗪/呋塞米
- **后果**：甘草的醛固酮样作用（水钠潴留+排钾）→对抗降压效果+加重利尿药的排钾→严重低钾血症
- **建议**：高血压患者避免长期服用含甘草的制剂

### 17. 含麻黄 → 降压药
- **组合**：感冒药（含麻黄碱/伪麻黄碱）+ 降压药
- **后果**：麻黄碱升压→降压效果被抵消→血压控制不良
- **建议**：高血压患者选用不含麻黄碱的感冒药

### 18. 含银杏叶提取物 → 抗凝/抗血小板药
- **组合**：银杏叶制剂 + 华法林/阿司匹林
- **后果**：银杏成分抑制血小板活化因子（PAF）→与抗凝药协同→出血风险增加
- **建议**：联用需谨慎，密切监测出血体征；择期手术前 7 天停用

## 六、营养素-药物相互作用

### 19. 钙剂/铁剂 + 甲状腺素
- **组合**：碳酸钙/硫酸亚铁 + 左甲状腺素钠
- **后果**：钙/铁与左甲状腺素在肠道形成不溶性络合物→甲状腺素吸收减少 30-40%
- **建议**：两者服用间隔 ≥4 小时

### 20. 维生素 K 丰富食物 + 华法林
- **组合**：大量绿叶蔬菜（菠菜、西兰花、羽衣甘蓝）+ 华法林
- **后果**：维生素 K 拮抗华法林的抗凝作用→INR 下降→血栓风险增加
- **建议**：保持日常绿叶蔬菜摄入量稳定，不要突然大量增减
