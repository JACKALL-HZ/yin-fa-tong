# 老年人用药核心原则

## 一、老年人药代动力学特点

随着年龄增长，老年人体内药物代谢发生以下变化：

- **吸收**：胃酸分泌减少，胃肠蠕动减慢，但总体对药物吸收影响有限
- **分布**：体脂增加→脂溶性药物分布容积增大（半衰期延长）；血浆白蛋白降低→蛋白结合率高的药物游离浓度升高，药效增强
- **代谢**：肝体积缩小 20-40%，肝血流量减少 40%→首过效应减弱，药物生物利用度升高。CYP450 酶活性下降，I 相代谢减慢
- **排泄**：肾小球滤过率每年下降约 1ml/min，80 岁时 GFR 约为青年人的 50-60%→经肾排泄药物半衰期显著延长

## 二、老年人用药六大原则

### 1. 受益原则
- 必须有明确的用药指征才能使用
- 权衡受益与风险：受益/风险比 > 1 才考虑用药

### 2. 五药原则（五种药物原则）
- 同时使用 ≤5 种药物时，药物相互作用风险约为 5%
- 同时使用 6-10 种药物，相互作用风险升至 50%
- 同时使用 ≥10 种药物，相互作用风险接近 100%
- **实践建议**：每增加一种药都要问"是否必须"，优先使用"一箭双雕"的药物

### 3. 小剂量原则
- 起始剂量通常为成人常规剂量的 **1/2 到 2/3**
- 肾功能减退者按肌酐清除率调整剂量
- 缓慢递增（"Start low, go slow"）
- 避免使用负荷剂量（除非紧急情况）

### 4. 择时原则
- 根据疾病昼夜节律选择最佳服药时间
- 例如：降压药晨起服用（控制清晨血压高峰）；他汀类降脂药睡前服用（胆固醇夜间合成高峰）；利尿剂早晨服用（避免夜尿增多影响睡眠和增加跌倒风险）

### 5. 暂停原则
- 当出现新症状，首先考虑是否为药物不良反应，其次才考虑新疾病
- 定期审查用药清单，停用无明确指征的药物（"Deprescribing"）
- 入院/出院/转科时需"药物重整"（Medication Reconciliation）

### 6. 非药物治疗原则
- 生活方式调整在用药之前：饮食、运动、心理调适
- 例如：轻度高血糖→饮食控制+运动 → 无效后再用口服降糖药
- 轻度高血压→限盐+减重+规律运动 3-6 个月 → 无效后再用降压药

## 三、老年潜在不适当用药（Beers 标准要点）

以下药物/类别在老年患者中使用风险较高，应尽量避免或慎用：

| 药物类别 | 风险 | 替代方案 |
|----------|------|----------|
| 苯二氮䓬类（地西泮、阿普唑仑） | 跌倒、认知损害、依赖 | 非药物睡眠干预、短程认知行为治疗 |
| 非选择性 NSAID（吲哚美辛、吡罗昔康） | 消化道出血、肾损害 | 对乙酰氨基酚、塞来昔布（短期慎用） |
| 第一代抗组胺药（苯海拉明、氯苯那敏） | 抗胆碱能：嗜睡、便秘、尿潴留、认知下降 | 第二代（氯雷他定、西替利嗪）或无抗胆碱能替代 |
| 三环类抗抑郁药（阿米替林） | 抗胆碱能、心脏毒性、体位性低血压 | SSRI（舍曲林、艾司西酞普兰） |
| 长效磺脲类（格列本脲） | 严重持续低血糖 | 短效磺脲类（格列吡嗪）或二甲双胍 |
| 骨骼肌松弛药（氯唑沙宗、美索巴莫） | 抗胆碱能、镇静、跌倒 | 理疗、局部热敷/冷敷 |
| 质子泵抑制剂（长期使用） | C.diff 肠炎、骨质疏松、维生素 B12 缺乏、肾损害 | 8-12 周标准疗程后评估是否停药，按需使用 |

## 四、药物不良反应的识别

老年患者药物不良反应表现常不典型，以下信号需警惕：

- **非特异性认知下降**（被误诊为"老年痴呆"）→ 检查是否与抗胆碱能药物、镇静药有关
- **跌倒增多**→ 检查是否使用降压药（体位性低血压）、镇静安眠药、降糖药（低血糖）
- **食欲下降、体重减轻**→ 检查是否与多药合用导致的胃肠反应有关
- **便秘加重**→ 检查是否与钙通道阻滞剂、利尿剂、含有铝/钙的胃药有关
- **排尿困难**→ 检查是否与抗胆碱能药物、感冒药（含伪麻黄碱/氯苯那敏）有关

## 五、服药依从性改善策略

老年人服药依从性差的主要原因及对策：

| 原因 | 对策 |
|------|------|
| 药片过多、方案复杂 | 简化方案、使用复方制剂、减少给药次数 |
| 视力下降看不清说明书 | 大字体标签、颜色区分、语音提示药盒 |
| 记忆力减退忘记服药 | 使用分格药盒、手机闹钟、家属提醒 |
| 自行停药（"感觉好了"） | 加强健康教育、强调规律用药的重要性（高血压/糖尿病等症状不明显但需长期治疗） |
| 吞咽困难 | 选择液体制剂/口腔崩解片、告知医师评估剂型调整 |
| 经济原因 | 在疗效相当前提下选择经济可负担的药品、告知医师 |

## 六、就诊用药沟通要点

每次就医时，请携带：

1. **完整的用药清单**（包括 OTC、保健品、中药）
2. **各药品的空药盒或说明书**
3. **近期检查报告**（肝肾功能、电解质等）
4. **过敏史记录**

需主动告知医师的问题：
- "我最近新加了什么药/保健品没有跟您提过？"
- "我现在吃的药有没有可以停的？"
- "这个新药和我现在吃的药会不会有冲突？"
- "以我的肝肾功能，这个药需要减量吗？"
