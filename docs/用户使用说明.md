## 1. 环境要求与启动

### 前提条件

- Docker Desktop 已安装并运行
- Docker 镜像加速器已配置（国内用户必配）

### 启动命令

```bash
cd e:\银发通二阶段项目
docker compose --project-name yft up -d
```

### 访问地址

| 服务 | 地址 | 用途 |
|---|---|---|
| 用户端（前端） | http://localhost | 患者/子女/管理员登录使用 |
| API 文档 | http://localhost:8000/docs | 后端接口调试（Swagger）|
| RabbitMQ 面板 | http://localhost:15672 | 消息队列监控（guest/guest）|

### 停止

```bash
docker compose --project-name yft down   # 停止所有服务
docker compose --project-name yft down -v  # 停止并清空数据卷（慎用）
```

## 2. 三种用户角色

| 角色 | user_type | 注册方式 | 核心功能 |
|---|---|---|---|
| **老年患者** | 1 | 直接注册 / 微信授权 | 长者极简 UI、预约挂号、AI 导诊、候诊排队、陪诊申请 |
| **子女代办** | 2 | 直接注册 | 标准 UI、绑定多名长辈、替长辈挂号缴费、查看长辈候诊进度 |
| **管理员** | 3 | 注册时账号必须以 `admin_` 开头 | 医院/科室/医生/排班管理、志愿者审核、订单管理、数据看板 |

### 界面模式

两种 UI 模式可在登录页或首页一键切换：

- **长者极简模式**：22px 大字体、高对比度、56px 触控按钮、精简导航
- **子女标准模式**：常规字体、完整功能导航、适合中青年操作

## 3. 老年患者使用指南

### 3.1 注册与登录

1. 打开 http://localhost，点击 **切换到长者极简模式**（默认在登录页右上角）
2. 选择 **账号密码登录**，输入手机号 + 密码，点击注册
3. 注册时 **user_type 选择 1（老年用户）**
4. 也可点击 **微信授权登录** 一键注册（模拟版直接输入任意 openid 即可）

### 3.2 预约挂号（核心功能）

1. 登录后进入首页，点击 **预约挂号** 大按钮
2. 按顺序选择：**医院 → 科室 → 医生 → 排班时段**
3. 选择号源类型：
   - **普通号**：常规号源
   - **老年优先号**：面向 60 岁以上，每时段保留 20% 专属号源
4. 确认预约 → 跳转支付 → 支付成功 → 获取候诊编号（NK 开头）

### 3.3 AI 智能导诊

1. 首页点击 **AI 智能导诊**
2. 输入症状描述（支持口语/方言，如"脑壳昏"、"心口疼"）
3. 系统匹配推荐科室 → 直接跳转挂号

### 3.4 候诊排队

1. 预约成功后自动进入候诊队列
2. 首页点击 **候诊排队** 查看：
   - 当前叫号号码
   - 前方还有 X 人排队
   - 预计等候 X 分钟

### 3.5 陪诊申请

1. 首页点击 **陪诊志愿者**
2. 浏览志愿者列表（头像/评分/服务次数/服务科室）
3. 点击志愿者查看详情 → **申请陪诊**
4. 选择陪诊日期，提交申请
5. 在 **我的陪诊订单** 查看审核进度：
   - 待审核 → 待服务 → 服务中 → 已完成 → 已取消
6. 服务完成后可评分 1-5 分 + 文字评价

### 3.6 健康提醒

首页 → **健康提醒**：查看用药/复诊/体检提醒，系统通过消息中心推送通知。

## 4. 子女代办用户使用指南

### 4.1 注册与登录

- 注册时 **user_type 选择 2（子女用户）**
- 默认使用 **子女标准模式**

### 4.2 绑定长辈

1. 登录后进入 **个人中心** → **长辈管理**
2. 点击 **添加长辈**，填写姓名、身份证号、出生日期、关系
3. 系统自动判定年龄：≥60 岁标记为"优先长者"

### 4.3 代长辈挂号

操作流程与老年患者相同，额外可选：
- **号源类型选"子女代办"** → 自动关联已绑定的长辈
- 挂号时选择具体为哪位长辈挂号

### 4.4 代缴费

1. 首页 → **我的订单**
2. 筛选状态 **待支付**，选择订单 → **去缴费**
3. 支持挂号费 / 检查费 / 药费三类模拟缴费

### 4.5 查看长辈候诊进度

1. 首页 → **候诊排队**，可切换查看已绑定长辈的排队状态
2. 消息中心实时接收长辈挂号、叫号通知

### 4.6 体检报告查询

1. 首页 → **体检报告**
2. 上传体检报告图片 → 系统 OCR 识别各项指标
3. 生成通俗大白话解读（数值+正常范围对照）

## 5. 管理员使用指南

### 5.1 注册与登录

- 注册时 **user_type 选 3**，**账号必须以 `admin_` 开头**
- 示例：`admin_zhangsan`
- 管理员白名单准入，非 `admin_` 前缀禁止注册管理员

### 5.2 登录后默认进入后台 Dashboard

访问 http://localhost → 登录 → 自动跳转 **数据统计看板**：
- 挂号总量统计
- 号源使用占比
- 科室热度 TOP10 图表

### 5.3 基础信息管理

| 功能 | 路径 | 操作 |
|---|---|---|
| 医院管理 | `/admin/hospitals` | 增删改查合作医院 |
| 科室管理 | `/admin/departments` | 管理各医院下属科室 |
| 医生管理 | `/admin/doctors` | 管理医生信息（职称/擅长/挂号费）|
| 排班管理 | `/admin/schedules` | 配置医生每日出诊时段、普通号/老年号数量 |

### 5.4 业务管理

| 功能 | 路径 | 操作 |
|---|---|---|
| 挂号订单 | `/admin/reserves` | 查看全部挂号记录、取消异常订单 |
| 陪诊订单 | `/admin/accompany` | 审核陪诊申请（通过/拒绝）|
| 志愿者管理 | `/admin/volunteers` | 增删改查志愿者信息、查看评分 |

### 5.5 数据看板

管理员首页 Dashboard 展示核心运营数据（ECharts 可视化）：
- 今日/本周挂号总量
- 号源类型占比饼图
- 科室预约热度柱状图
- 陪诊订单状态分布

## 6. 核心功能操作流程

### 预约挂号全流程

```
登录 → 选择医院 → 选择科室 → 选择医生 → 选择时段
    → 选择号源类型（普通/老年/代办）
    → 确认预约 → 线上支付 → 获取 NK 候诊编号
    → 候诊排队 → 就诊完成
```

### 陪诊全流程

```
浏览志愿者 → 查看详情 → 提交陪诊申请
    → 管理员审核 → 审核通过 → 待服务
    → 志愿者开始服务 → 服务中 → 服务完成
    → 用户评价 → 已完成（评分更新志愿者均分）
```

### 体检报告流程

```
上传报告图片 → OCR 识别 → 提取指标数值
    → 规则引擎对照正常范围 → 生成通俗解读 → 展示结果
```

## 7. 常见问题

### Q: 注册管理员时提示"管理员账号需以 admin_ 为前缀"？
A: user_type=3 时，username 必须以 `admin_` 开头，如 `admin_wangwu`。

### Q: 号源已满预约失败？
A: 尝试选择其他时段，或等待 15 分钟未支付自动取消的号源释放。

### Q: 如何切换长者/子女模式？
A: 登录页右上角或首页顶部有模式切换按钮，两种模式可随时切换。

### Q: 长辈如何被识别为长者？
A: 子女在"长辈管理"添加长辈信息时，系统根据出生日期自动判定（≥60 岁）。

### Q: 体检报告 OCR 支持哪些格式？
A: 支持 PNG/JPG 图片格式，要求拍摄清晰、文字无倾斜。

### Q: 项目数据库表是如何创建的？
A: 首次 Docker 启动时，后端容器自动执行 `alembic upgrade head` 建表。

### Q: 如何重置所有数据？
A: `docker compose --project-name yft down -v` 会删除所有数据卷，再 `up -d` 重新初始化。
