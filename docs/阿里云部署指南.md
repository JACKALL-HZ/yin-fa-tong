# 银发通 — 阿里云 ECS 部署指南

## 1. 服务器选购

### 1.1 推荐配置

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 规格 | 2 核 4GB | 4 核 8GB |
| 系统盘 | 40GB SSD | 60GB SSD |
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| 带宽 | 3Mbps | 5Mbps |

> MySQL + Redis + RabbitMQ + ES + 后端 + 前端全跑在一台机器上，4GB 内存是底线。

### 1.2 购买步骤

1. 登录 [阿里云控制台](https://ecs.console.aliyun.com)
2. 选择 **华东 1（杭州）** 或离你最近的地域
3. 实例规格 → 选择 **ecs.c6.xlarge**（4C8G）或 **ecs.c6.large**（2C4G）
4. 镜像 → **Ubuntu 22.04 LTS 64位**
5. 存储 → 系统盘 60GB SSD
6. 网络 → 分配**公网 IP**，带宽 5Mbps
7. 安全组 → 选择或创建（下一步配置）
8. 设置 root 密码，完成购买

## 2. 安全组配置

在 ECS 实例详情 → 安全组 → 配置规则 → 入方向添加：

| 协议 | 端口 | 来源 | 说明 |
|------|------|------|------|
| TCP | 22 | 0.0.0.0/0 | SSH |
| TCP | 80 | 0.0.0.0/0 | HTTP（Nginx） |
| TCP | 443 | 0.0.0.0/0 | HTTPS |
| TCP | 3307 | 你的 IP/32 | MySQL（仅调试用，上线后关闭） |
| TCP | 5672 | 你的 IP/32 | RabbitMQ（仅调试用） |
| TCP | 15672 | 你的 IP/32 | RabbitMQ 管理界面（仅调试用） |

> **安全原则**：生产环境只开 80/443/22，数据库端口通过 SSH 隧道访问。

## 3. 服务器环境安装

### 3.1 SSH 登录

```bash
ssh root@你的公网IP
```

### 3.2 安装 Docker + Docker Compose

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 验证 Docker
docker --version

# 安装 Docker Compose（V2 插件）
apt install docker-compose-plugin -y

# 验证
docker compose version
```

### 3.3 配置 Docker 镜像加速（国内必做）

```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://registry.docker-cn.com"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
EOF

systemctl daemon-reload
systemctl restart docker
```

## 4. 上传项目代码

### 4.1 方式一：Git 拉取（推荐）

```bash
# 如果代码在 Git 仓库
cd /opt
git clone https://你的仓库地址.git yinfa-tong
```

### 4.2 方式二：SCP 上传

在本地电脑执行：

```bash

cd "e:/银发通二阶段项目"

    -czf yinfa-tong.tar.gz .

# 在服务器上解压
ssh root@你的公网IP
cd /opt
mkdir yinfa-tong && cd yinfa-tong
tar -xzf /opt/yinfa-tong.tar.gz
rm /opt/yinfa-tong.tar.gz
```

## 5. 环境变量配置

### 5.1 创建生产环境配置

```bash
cd /opt/yinfa-tong
cp .env.example .env  # 如果有模板
# 或者直接创建
cat > .env << 'EOF'
# ── 应用 ──
APP_NAME=银发通
APP_VERSION=1.0.0
DEBUG=false

# ── 数据库 ──
DB_HOST=mysql
DB_PORT=3306
DB_USER=root
DB_PASSWORD=替换为强密码_至少16位
DB_NAME=yinfa_tong

# ── Redis ──
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_PASSWORD=替换为强密码
REDIS_DB=0

# ── RabbitMQ ──
RABBITMQ_HOST=rabbitmq
RABBITMQ_PORT=5672
RABBITMQ_USER=admin
RABBITMQ_PASSWORD=替换为强密码

# ── Elasticsearch ──
ES_HOST=elasticsearch
ES_PORT=9200

# ── JWT ──
JWT_SECRET_KEY=替换为随机字符串_至少32位
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=1440

# ── 文件上传 ──
UPLOAD_DIR=uploads
MAX_UPLOAD_SIZE_MB=10

# ── Dify AI ──
DIFY_API_KEY=你的Dify_API_Key
DIFY_BASE_URL=https://api.dify.ai
DIFY_APP_MODE=chatflow
DIFY_TIMEOUT=60
DIFY_MAX_RETRIES=1

# ── 支付宝沙箱 ──
ALIPAY_APP_ID=你的AppID
ALIPAY_PRIVATE_KEY=你的私钥
ALIPAY_PUBLIC_KEY=支付宝公钥
ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do
ALIPAY_NOTIFY_URL=http://你的公网IP/api/payment/notify
ALIPAY_RETURN_URL=http://你的公网IP/pay-result
PAY_MODE=sandbox

# ── MySQL root 密码（docker-compose 用）──
MYSQL_ROOT_PASSWORD=替换为强密码_至少16位
EOF
```

### 5.2 生成安全密钥

```bash
# 生成 JWT 密钥
python3 -c "import secrets; print(secrets.token_urlsafe(48))"

# 生成数据库密码
python3 -c "import secrets; print(secrets.token_urlsafe(16))"
```

## 6. 修改 Docker Compose（生产模式）

### 6.1 移除开发覆盖文件

```bash
# 删除 override 文件（它会挂载本地代码 + 启用 --reload）
rm -f docker-compose.override.yml
```

### 6.2 修改 MySQL 端口（不暴露到宿主机）

编辑 `docker-compose.yml`，将 MySQL 的端口映射改为仅内部访问：

```yaml
mysql:
  # 删除或注释掉 ports 段，容器内部网络自动可达
  # ports:
  #   - "3307:3306"
```

同理关闭 Redis、RabbitMQ、ES 的端口映射：

```yaml
redis:
  # ports:
  #   - "6379:6379"

rabbitmq:
  # ports:
  #   - "5672:5672"
  #   - "15672:15672"

elasticsearch:
  # ports:
  #   - "9200:9200"
```

只保留 backend 和 frontend 的端口：

```yaml
backend:
  ports:
    - "8000:8000"

frontend:
  ports:
    - "80:80"
```

## 8. Nginx 反向代理（可选，有域名时）

### 8.1 安装 Nginx

```bash
apt install nginx -y
```

### 8.2 配置站点

```bash
cat > /etc/nginx/sites-available/yinfa-tong << 'EOF'
server {
    listen 80;
    server_name 你的域名.com;  # 替换为真实域名

    # 前端静态资源
    location / {
        proxy_pass http://127.0.0.1:80;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }
}
EOF

# 启用站点
ln -sf /etc/nginx/sites-available/yinfa-tong /etc/nginx/sites-enabled/
nginx -t  # 测试配置
systemctl reload nginx
```

### 8.3 申请 HTTPS 证书（Let's Encrypt）

```bash
# 安装 certbot
apt install certbot python3-certbot-nginx -y

# 申请证书（需要域名已解析到此 IP）
certbot --nginx -d 你的域名.com

# 自动续期
echo "0 3 * * * certbot renew --quiet" | crontab -
```

## 9. 支付宝回调配置

### 9.1 内网穿透（开发/演示用）

如果服务器没有域名，用 natapp 做内网穿透：

```bash
# 下载 natapp
wget https://natapp.cc/downloads/natapp_linux_amd64.zip
unzip natapp_linux_amd64.zip
chmod +x natapp

# 启动（需要在 natapp.cc 注册并获取 authtoken）
./natapp -authtoken=你的token
```

natapp 会分配一个公网域名如 `xxx.natappfree.cc`，将 `.env` 中的 `ALIPAY_NOTIFY_URL` 改为：

```
ALIPAY_NOTIFY_URL=http://xxx.natappfree.cc/api/payment/notify
```

### 9.2 正式环境（有域名）

直接用域名：

```
ALIPAY_NOTIFY_URL=https://你的域名.com/api/payment/notify
ALIPAY_RETURN_URL=https://你的域名.com/pay-result
```

## 10. 常用运维命令

```bash
# 查看所有容器状态
docker compose ps

# 查看实时日志
docker compose logs -f backend
docker compose logs -f frontend

# 重启单个服务
docker compose restart backend

# 数据库备份
docker compose exec mysql mysqldump -uroot -p$DB_PASSWORD yinfa_tong > backup_$(date +%Y%m%d).sql

docker compose exec -T mysql mysql -uroot -p$DB_PASSWORD yinfa_tong < backup_20260625.sql

# 清理无用镜像
docker system prune -a
```

## 11. 常见问题

### Q1: ES 启动失败，内存不足

```bash
# 查看 ES 日志
docker compose logs elasticsearch | grep -i "memory|oom"

# 解决：调小 ES 内存
# docker-compose.yml 中修改：
environment:
  - "ES_JAVA_OPTS=-Xms128m -Xmx128m"
```

### Q2: RabbitMQ 插件未加载

```bash
# 进入容器检查插件
docker compose exec rabbitmq rabbitmq-plugins list | grep delayed

# 如果没有，检查 Dockerfile 是否正确安装了插件
cat docker/rabbitmq/Dockerfile
```

### Q3: 后端启动后数据库表不存在

```bash
# 执行数据库迁移
docker compose exec backend alembic upgrade head
```

### Q4: 前端页面空白

```bash
# 检查 Nginx 配置
docker compose logs frontend

# 确认 dist 目录存在
docker compose exec frontend ls /usr/share/nginx/html/
```

### Q5: 支付宝回调收不到

```bash
# 检查回调地址是否公网可达
curl -X POST http://你的域名/api/payment/notify

# 检查安全组是否开放 80/443 端口
# 检查 natapp 是否正常运行
```
