## 1. 端口映射问题

### 1.1 问题描述

Docker 多容器架构中涉及 6 个服务（MySQL、Redis、RabbitMQ、Elasticsearch、Backend、Frontend），需要合理配置端口映射：生产环境保证安全性，开发环境保留调试能力。

### 1.2 解决方案

**分层端口策略：**

| 层级 | 端口策略 | 说明 |
|------|----------|------|
| 对外层 | 仅暴露 80 端口 | Nginx 反向代理统一入口 |
| 服务层 | 内部端口不暴露 | Backend:8000 通过 Docker 网络通信 |
| 数据层 | 完全隔离 | MySQL:3306、Redis:6379、RabbitMQ:5672、ES:9200 |

**生产环境配置**（[docker-compose.yml](docker-compose.yml)）：

```yaml
services:
  mysql:
    # ports: "3307:3306"  # 生产不暴露
  redis:
    # ports: "6379:6379"
  rabbitmq:
    # ports: "5672:5672", "15672:15672"
  elasticsearch:
    # ports: "9200:9200"
  backend:
    # ports: "8000:8000"  # 通过 Nginx 反代
  frontend:
    ports:
      - "80:80"  # 唯一对外端口
```

**开发环境覆盖**（[docker-compose.override.yml](docker-compose.override.yml)）：

```yaml

    volumes:
      - ./backend/app:/app/app  # 挂载代码热重载
    command: sh -c "alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload"
```

## 3. 延迟支付的问题解决

### 3.1 问题描述

挂号预约场景中，用户创建订单后需在规定时间内完成支付。超时未支付需自动取消并回收号源。需处理并发回调和状态一致性。

### 3.2 订单状态机

```
创建订单 (pay_status=1)
    │
    ├─→ 支付成功 (pay_status=2) → 入候诊队列 (queue_status=1)
    │
    └─→ 超时未付 (pay_status=3) → 号源回收
```

### 3.3 超时控制实现

文件：[backend/app/payment/service.py](backend/app/payment/service.py)

```python
async def create_payment(session, req, user_id):

    existing = await pay_repo.get_by_reserve_id(session, req.reserve_id)
    if existing and existing.pay_status == 1:
        # 计算已过去时间
        created = existing.create_time.replace(tzinfo=timezone.utc)
        elapsed = (datetime.now(timezone.utc) - created).total_seconds()
        if elapsed > 15 * 60:  # 15 分钟超时
            await pay_repo.mark_closed(session, existing.out_trade_no)
            raise ValueError("支付已超时，请重新预约")
        out_trade_no = existing.out_trade_no  # 复用未超时订单
```

**双重超时保障：**
1. 后端检查：创建支付时校验已有记录是否超时
2. 支付宝侧：`model.timeout_express = "15m"` 设置订单有效期

### 3.4 并发安全处理

**幂等更新（Repository 层）：**

## 4. 支付宝沙箱支付的问题

### 4.1 问题描述

对接支付宝沙箱环境遇到的问题：
1. 密钥格式不兼容（PKCS#1 vs PKCS#8）
2. 异步回调验签失败
3. 沙箱环境不稳定需降级
4. 回调可能丢失需兜底方案

### 4.2 密钥格式处理

文件：[backend/app/payment/service.py](backend/app/payment/service.py)

```python
def _format_private_key(key_str: str) -> str:
    """支持裸 base64 / PKCS#8 / PKCS#1 三种格式"""
    key_str = key_str.strip()
    if key_str.startswith("-----BEGIN RSA PRIVATE KEY-----"):
        return key_str  # 已是 PKCS#1
    
    # 去掉 PEM 头尾
    if "-----" in key_str:
        for tag in ["BEGIN PRIVATE KEY", "END PRIVATE KEY", 
                     "BEGIN RSA PRIVATE KEY", "END RSA PRIVATE KEY"]:
            key_str = key_str.replace(f"-----{tag}-----", "").strip()
    
    try:
        # 尝试 DER → PKCS#1 转换
        from cryptography.hazmat.primitives.serialization import (
            load_der_private_key, Encoding, PrivateFormat, NoEncryption
        )
        der = base64.b64decode(key_str)
        private_key = load_der_private_key(der, password=None)
        pem = private_key.private_bytes(Encoding.PEM, PrivateFormat.TraditionalOpenSSL, NoEncryption())
        return pem.decode("utf-8")
    except Exception:
        # fallback：直接包装 PEM 头
        lines = ["-----BEGIN RSA PRIVATE KEY-----"]
        for i in range(0, len(key_str), 64):
            lines.append(key_str[i:i+64])
        lines.append("-----END RSA PRIVATE KEY-----")
        return "\n".join(lines)
```

### 5.4 多索引模糊搜索

文件：[backend/app/search/repository.py](backend/app/search/repository.py)

```python
# 搜索字段及权重
_SEARCH_FIELDS = {
    "hospital": ["hospital_name^3", "address"],
    "department": ["dept_name^3", "hospital_name"],
    "doctor": ["doctor_name^3", "specialty^2", "dept_name", "hospital_name", "doctor_title"],
    "symptom": ["keywords^3", "dept_name"],
}

async def search_multi(es, keyword, search_types, size=50):
    indices = _resolve_indices(search_types)
    
    # 合并所有类型的搜索字段
    all_fields = []
    for st in search_types:
        all_fields.extend(_SEARCH_FIELDS.get(st, []))
    
    query_body = {
        "query": {
            "multi_match": {
                "query": keyword,
                "fields": all_fields,
                "type": "best_fields",  # 每文档取最佳匹配字段分数
            }
        },
        "size": size,
    }
    
    result = await es.search(index=indices, body=query_body)
    return {"total": result["hits"]["total"]["value"], "hits": result["hits"]["hits"]}
```

**为什么用 `best_fields` 而非 `cross_fields`：**
- `best_fields`：每个文档只取最佳匹配字段的分数，避免多字段弱匹配导致排名虚高
- 例：搜索"头疼"，医生A的doctor_name匹配得分0.8，医生B的specialty和dept_name各得0.3，best_fields 选最高分，医生A排前面

## 8. Redis 回滚机制

### 8.1 问题描述

挂号预约场景中，号源扣减需保证原子性。支付失败或超时时需回滚号源。需处理并发扣减一致性。

### 8.2 Lua 原子扣减脚本

文件：[backend/app/shared/redis.py](backend/app/shared/redis.py)

```python
LUA_DECREASE_SOURCE = """
local normal_key = KEYS[1]
local elder_key = KEYS[2]
local source_type = ARGV[1]
local delta = tonumber(ARGV[2])

if source_type == "normal" then
    local current = tonumber(redis.call('GET', normal_key) or 0)
    if current >= delta then
        redis.call('DECRBY', normal_key, delta)
        return 1
    else
        return 0
    end
elseif source_type == "elder" then
    local current = tonumber(redis.call('GET', elder_key) or 0)
    if current >= delta then
        redis.call('DECRBY', elder_key, delta)
        return 1
    else
        return 0
    end
end
return 0
"""

async def decrease_source_redis(schedule_id, source_type):
    r = await get_redis()
    normal_key = f"source:{schedule_id}:normal"
    elder_key = f"source:{schedule_id}:elder"
    result = await r.eval(LUA_DECREASE_SOURCE, 2, normal_key, elder_key, source_type, 1)
    return result == 1
```

**关键设计：**
- 先检查库存 `>= delta` 再扣减，避免负数
- 返回 1 表示成功，0 表示不足
- Lua 脚本在 Redis 单线程执行，天然原子

```python
    redis.call('INCRBY', normal_key, delta)

"""
```

```python
LUA_ADJUST_SOURCE = """
local key = KEYS[1]
local delta = tonumber(ARGV[1])
local current = tonumber(redis.call('GET', key) or 0)
local new_val = current + delta
if new_val < 0 then new_val = 0 end  -- 下限保护
redis.call('SET', key, new_val)
return new_val
"""

async def adjust_source_redis(schedule_id, source_type, delta):
```

### 9.6 JSON 解析与校验节点

```python
import json, re

def main(llm_output: str) -> dict:
    default = {
        "departments": [], "medications": [],
        "elderly_precautions": "", "emergency_flag": False, "general_advice": ""
    }
    
    if not llm_output:
        return {"result": json.dumps(default, ensure_ascii=False)}
    
    # 提取 JSON：先匹配代码块，再匹配裸花括号
    parsed = None
    m = re.search(r'```(?:json)?\s*([\s\S]*?)```', llm_output)
    if m:
        try: parsed = json.loads(m.group(1))
        except: pass
    
    if parsed is None:
        m = re.search(r'\{[\s\S]*\}', llm_output)
        if m:
            try: parsed = json.loads(m.group())
            except: pass
    
    if not isinstance(parsed, dict):
        return {"result": json.dumps(default, ensure_ascii=False)}
    
    # 合并默认值 + 校验字段
    result = {**default, **{k: v for k, v in parsed.items() if k in default}}
    result["departments"] = [
        {"dept_name": d["dept_name"], "confidence": min(1.0, max(0.0, d.get("confidence", 0.5))), "reasoning": d.get("reasoning", "")}
        for d in result.get("departments", [])[:3] if d.get("dept_name")
    ]
    result["medications"] = [
        {"drug_name": m["drug_name"], "indication": m.get("indication", ""), "dosage_note": m.get("dosage_note", ""), "elderly_precaution": m.get("elderly_precaution", ""), "contraindication": m.get("contraindication", "")}
        for m in result.get("medications", [])[:3] if m.get("drug_name")
    ]
    result["emergency_flag"] = bool(result.get("emergency_flag", False))
    
    return {"result": json.dumps(result, ensure_ascii=False)}
```
